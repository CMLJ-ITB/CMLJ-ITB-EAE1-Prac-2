# 🎯 Angry-Shooter | CMLJ-ITB-EAE1-Prac-2

**Angry-Shooter** és un mini-joc d'estratègia i habilitat en el qual controles una catapulta per encertar tots els objectius i superar cada nivell.

## ✨ Característiques principals

* **Nivells desafiants:** Posa a prova el teu enginy en mapes amb limitacions i obstacles únics.
* **Sistema de progressió:** Puja de nivell per desbloquejar nou equipament i projectils especials amb els quals adaptar la teva estratègia.
* **Competició global:** Compara la teva puntuació amb la dels teus amics o escala posicions en el rànquing mundial.
